# 📖 読書ノート to note | アイデア集積PWA

紙の本を読みながら、目次ツリーに沿って音声やテキストで知識・思考を集積し、note記事（雪国アーキパパ視点）の企画・構成案をワンクリックで生成する完全クライアント型PWAです。

---

## 🌟 主な特徴・機能

1. **完全クライアント型 PWA（インストール対応）**
   - サーバーへのデータ送信なし（完全プライベート・高セキュリティ）。
   - ブラウザの IndexedDB に書籍・目次・メモを自動保存（オフライン動作対応）。
   - スマホの「ホーム画面に追加」でネイティブアプリ感覚で起動。

2. **【新機能】本の表紙・背後撮影で書籍情報を自動転記（Gemini Vision）**
   - スマホで本の「表紙（表）」と「背後・裏表紙・奥付（裏）」を撮影するだけで、タイトル、著者名、出版年月、出版社、背後説明文（あらすじ・キャッチコピー）、テーマを自動抽出。
   - 入力フォームに瞬時に転記され、表紙写真も書籍サムネイルとして自動保存・美しく表示。

3. **【新機能】複数ページに及ぶ目次のスマート連続取込・並び替え・統合ツリー化**
   - 目次が2〜4ページ以上にわたる場合も、1ページずつ確認しながら「＋ ページを追加」で連続撮影可能。
   - サムネイルカードに「P.1」「P.2」等のバッジが表示され、「◀」「▶」で順番を自在に入れ替え、不要なピンボケ写真は「✕」で即座に削除。
   - 改ページをまたぐ章・節もAIが1本の連続したツリーに自動結合し、保存前に「パース結果プレビュー」で確認・確定できる安心設計。

4. **読書の集中を妨げないワンタップ音声＆テキストメモ**
   - 読書中、目次の該当する節をワンタップして音声入力（Web Speech API）またはフリック入力。
   - リアルタイムで文字起こしされ、サクサク記録可能。

5. **AIによる自動3層構造化カード（Gemini連携）**
   - 吹き込んだ生メモから、AIが以下の3要素を瞬時に自動生成してカード保存：
     - 📌 **【要点サマリー】**: 書籍内容の本質・重要事実
     - 💡 **【塩崎様の気づき・考察】**: 一級建築士・ゼネコン施工管理・建築補償・不動産投資目線での独自考察
     - ✍️ **【note記事の切り口】**: 「雪国アーキパパ」としての読者向け発信テーマ

6. **note記事 企画・構成案スタジオ（ワンクリック生成）**
   - 蓄積されたメモから、note記事の「タイトル案3本」「ターゲット読者」「導入（リード文）」「見出し構成（H2/H3）」「雪国アーキパパならではの独自価値」「執筆アドバイス」を完全自動生成。
   - クリップボードへのMarkdownコピーやファイル保存に対応。

7. **安心のデータ管理**
   - ワンクリックで全データをJSON形式でエクスポート（バックアップ）・復元可能。

## 🚀 起動・使用方法

### 1. PCブラウザで開く場合
ターミナルで以下のコマンドを実行し、ブラウザでアクセスします：
```bash
python3 /home/sconstructionbenefit/brain/note/20260914_読書メモ_noteアイデア集積PWA/run_app.py
```
ブラウザで [http://localhost:8088](http://localhost:8088) を開きます。

### 2. スマートフォンで使う場合（推奨：GitHub Pages 永続公開）
本アプリは専用の公開リポジトリにて GitHub Pages が完全稼働しています。PCの起動不要で、スマートフォン単体から24時間いつでもアクセス・利用可能です。

🔗 **本番アクセスURL**:
👉 **[https://sconstructionbenefit-dotcom.github.io/book-note-pwa/](https://sconstructionbenefit-dotcom.github.io/book-note-pwa/)**

#### ホーム画面への追加手順
1. スマートフォンの Safari（iPhone）または Chrome（Android）で上記URLを開く。
2. **iPhoneの場合**: 画面下の「共有ボタン」→ **「ホーム画面に追加」** をタップ。
3. **Androidの場合**: 右上の「メニュー」→ **「ホーム画面に追加」** または **「アプリをインストール」** をタップ。
4. ホーム画面に専用アイコン（📖 **読書note**）が生成され、全画面アプリとして起動可能になります。

## 🌐 インターネット公開・どこでも使える設定（PC起動不要・外出先・職場対応）

PCの電源を落としていても、職場や外出先（4G/5G・カフェ・電車内・オフライン）からスマホ単体でいつでも開けるようにする設定です。

### 最も簡単な方法：Cloudflare Pages（無料・ドラッグ＆ドロップで完了）
1. [Cloudflare ダッシュボード](https://dash.cloudflare.com/) にアクセス（Google等で無料登録可能）。
2. 左側メニューの「**Workers & Pages**」➔「**作成 (Create application)**」をクリック。
3. 上部タブの「**Pages**」➔「**アセットをアップロード (Upload assets)**」を選択。
4. プロジェクト名（例: 
eading-note-pwa）を入力。
5. 本フォルダ内の **
eading_note_pwa_deploy.zip**（または public_deploy フォルダ）を枠内にドラッグ＆ドロップ。
6. 「**サイトのデプロイ**」をクリックすると、わずか数秒で常時アクセス可能な専用URL（https://xxxx.pages.dev）が発行されます。
7. スマートフォンのブラウザでそのURLを開き、「**ホーム画面に追加**」してください。
